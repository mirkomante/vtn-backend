# Guides

Questa cartella contiene guide e documentazione di riferimento per sviluppatori.

## 📚 Guide Disponibili

- **[Database Schema](./database-schema.md)** - Schema completo del database con tutti i modelli, campi e relazioni
- **[Standard Messages](./standard-messages.md)** - Messaggi standardizzati del sistema per coerenza e professionalità

## 🎯 Come Usare Queste Guide

### Per Sviluppatori Backend
1. **Inizia con** [Database Schema](./database-schema.md) per capire la struttura dati
2. **Consulta** [Standard Messages](./standard-messages.md) per i messaggi del sistema

### Per Sviluppatori Frontend
1. **Riferisciti** a [Database Schema](./database-schema.md) per capire i dati disponibili
2. **Usa** [Standard Messages](./standard-messages.md) per messaggi consistenti

### Per Integratori
1. **Leggi** [Database Schema](./database-schema.md) per capire la struttura dati
2. **Consulta** [Standard Messages](./standard-messages.md) per i messaggi standardizzati

## 📝 Note per Sviluppatori

- Il database schema è la fonte di verità per la struttura dati
- I messaggi standardizzati garantiscono coerenza nell'interfaccia utente
- Tutte le guide includono esempi pratici di utilizzo
- Le guide vengono aggiornate quando cambia la struttura del sistema

## 🔄 Manutenzione

Queste guide vengono aggiornate quando:
- Viene modificato lo schema del database
- Vengono aggiunti nuovi modelli o campi
- Vengono cambiati i messaggi standardizzati
- Vengono aggiunte nuove funzionalità che richiedono documentazione
