# Systems Documentation

Questa cartella contiene la documentazione dei sistemi e componenti principali dell'applicazione VTN Backend.

## 📋 Sistemi Disponibili

### 🎨 Interfaccia Utente
- **[Toast System](./toast-system.md)** - Sistema di notifiche toast per feedback utente
- **[Form Manager](./form-manager.md)** - Gestione unificata di tutti i form dell'applicazione
- **[Detail Views](./detail-views.md)** - Sistema di viste in dettaglio centralizzate

### 📊 Gestione Dati
- **[Pagination](./pagination.md)** - Sistema di paginazione per tabelle con grandi quantità di dati
- **[Script Management](./script-management.md)** - Gestione centralizzata degli script JavaScript

### 🔧 Infrastruttura
- **[Logging](./logging.md)** - Sistema di logging avanzato con database PostgreSQL

## 🎯 Come Usare Questa Documentazione

### Per Sviluppatori Frontend
1. **Inizia con** [Form Manager](./form-manager.md) per gestire i form
2. **Consulta** [Toast System](./toast-system.md) per le notifiche
3. **Usa** [Detail Views](./detail-views.md) per le viste in dettaglio

### Per Sviluppatori Backend
1. **Riferisciti** a [Logging](./logging.md) per il sistema di log
2. **Consulta** [Pagination](./pagination.md) per le tabelle
3. **Usa** [Script Management](./script-management.md) per gli script

### Per Integratori
1. **Leggi** [Form Manager](./form-manager.md) per capire i form
2. **Consulta** [Toast System](./toast-system.md) per le notifiche
3. **Riferisciti** a [Detail Views](./detail-views.md) per le viste
